# 낱말 조각 공방

지문 속 단어로 하는 2단계 단어 게임이에요. 학생은 로그인 없이 링크만 열면 됩니다.

- **1단계:** 영어 ↔ 문맥상 뜻 짝 맞추기 → 퍼즐 조각 생성 → 2D 퍼즐 완성
- **2단계:** 쉬운 예문 빈칸 채우기 → 맞힐 때마다 에너지가 쌓이고, 가득 차면 기관(병원·학교·관람차·성 …) 하나가 무작위로 완공
- 다 끝내면 학생 이름·실수·걸린 시간·기관이 선생님 구글 시트에 자동 기록
- **반별 마을:** 학생이 활동 한 세트를 끝낼 때마다 그 반 마을에 기관이 하나씩 세워져요. 반마다 마을을 나란히 비교할 수 있어요.

## 주소

- 교사 화면: `https://ereyang.github.io/my-vocab/word-puzzle/`
- 학생 링크: 교사 화면에서 문제를 저장하면 `...?set=w1234abcd` 형태로 만들어져요.
- 반별 마을: `https://ereyang.github.io/my-vocab/word-puzzle/?village` (한 반만: `?village=2-3`)
- 연습용 예시: `https://ereyang.github.io/my-vocab/word-puzzle/?set=sample`

## 처음 한 번: 구글 시트 연결 (약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `낱말 조각 공방`으로 정해요.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 코드를 지우고 `apps-script/WordPuzzle.gs` 내용을 통째로 붙여 넣은 뒤 저장해요.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `TEACHER_PASSWORD`
   - 값: 선생님만 아는 비밀번호
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포를 누르고 권한을 허용해요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 Claude에게 알려 주세요.
   `app.js` 맨 위 `API_URL`에 넣어 드려요.

> "모든 사용자"로 해야 학생이 로그인 없이 제출할 수 있어요. 학교 도메인 사용자만 허용하면 학교 계정으로 로그인한 학생만 제출돼요.

## 문제 만들기

1. **출제** 탭에 지문을 붙여 넣고, 지문 속 단어를 눌러 최대 12개를 골라요.
2. **AI에게 보낼 질문 복사**를 누르고 Claude 대화창에 붙여 넣어요.
   Claude 앱 페이지에서 만든 문제는 **깃허브로 내보내기** 코드를 대신 붙여 넣어도 돼요.
3. 답을 3번 칸에 붙여 넣고 **적용**을 누른 뒤, 뜻과 예문을 확인해요.
4. 교사 비밀번호를 적고 **저장하고 링크 만들기**를 누르면 학생 링크가 나와요.

## 마을 규칙

- 학생은 시작할 때 **학번 5자리 + 이름**(예: `20315 김민지`)을 적어요. 앞 세 자리로 반(2학년 3반)을 알아내요.
- 단어 하나 = 에너지 1, 활동 1세트 완료 = 기관 1개, 반 마을 = 그 반 학생들이 지은 기관 전부.
- 기관은 그 반에 아직 없는 것 중에서 무작위로 나와요 (보통 19종 · 희귀 5종 · 전설 1종). 다 모이면 다시 아무거나 나와요.
- 같은 학생이 같은 활동을 다시 끝내도 기관은 처음 받은 하나만 남아요.
- 마을을 처음부터 다시 시작하려면 **반별 마을** 탭 아래 **마을 초기화**에서 반(또는 전체 반)을 고르고 교사 비밀번호로 초기화해요. 명단·점수는 남고, 지었던 기관은 결과 탭 `archived` 칸에 기록돼요.

## 명단 보기

**내 문제·명단** 탭에서 문제 옆의 **명단 보기**를 누르고 교사 비밀번호를 적어요.
같은 내용이 구글 시트의 **결과** 탭에도 한 줄씩 쌓여요.
